# Ideas Backlog

Ideas for after the MVP. Nothing here is planned yet; each line says what it is and why it may help. Add new ideas at the end of the right section.

## Recording expenses

- **Receipt photo** on an expense, so anyone can check the amount later.
- **Unequal split:** split by amount, percentage or shares (for example, one person ate twice as much), not only equally.
- **Amount as a formula** (`2048000-195000-585000`), like the sheet allows today.
- **Quick add from the phone:** one-screen form with the last payer and "everyone" remembered.
- **Offline entry:** record expenses with no internet and sync later (useful abroad without a SIM card).
- **Custom expense types per trip** (the MVP has a fixed list).
- **Templates for repeated trips** (for example, the yearly hospital check-up in Vietnam): copy participants, sponsors and expense types from an earlier trip.

## Money

- **Live exchange rates** from a public rate service, with the option to lock the rate for the trip.
- **Different rate per expense** (the rate on the day it was paid).
- **Record a settlement payment** ("Person B paid Person D 322.45 USD") so the balance goes to zero inside the app instead of a remark.
- **Choose the settlement currency** (show the "who pays whom" list in USD, KHR or VND).

## People and access

- **Viewer role:** can see a trip but not change it.
- **Invite link** for a trip, so the owner does not need to add members one by one.
- **Email or Telegram login link** (no password to remember).
- **Notifications** (Telegram bot) when an expense is added or a trip is settled.

## Reports

- **Export to Excel/CSV** in the same layout as the old spreadsheet.
- **Import old spreadsheets** (`archive/share_expense_history_2025_2026.xlsx`) so the history lives in the app.
- **Charts:** spending by type and by day.
- **History across trips:** how much each person spent per year.

## Interface

- **Khmer translation** of the interface (the text is translation-ready from V1).
- **Dark mode.**
- **Country flag** on the trip card (the sheet shows one with `flagsapi.com`).

## Open source

- **One-command self-hosting** guide (Docker Compose) and a demo trip with fake data.
- **Hosted demo** with a reset every night.
